# hxwl-03 岩土钻孔编录

钻孔分层、标贯与地下水位的现场记录面板

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 功能

- 连续作业台账：分层记录持久化在本机浏览器（localStorage），重开自动恢复
- 同一孔号按层底深度排队；同深度保存会先提示将覆盖的旧记录，确认才替换，取消则原样保留
- 地下水位取最近一次记录；水位深于该孔最深层底时拦截保存并说明原因
- 累计孔深、地层数量、最高标贯、地下水位与岩性筛选均由台账实时重算
- 导出摘要与页面共用同一份台账；支持 JSON 备份 / 导入，便于换设备迁移
- 可继续扩展 IndexedDB、权限、后端 API 和复杂图表
